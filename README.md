# K.Williams Portfolio
Design and Development portfolio

Project Description:
This project is a multi-page portfolio website designed and developed to showcase my work as a UX/UI designer and front-end developer. The site highlights both professional and exploratory projects, combining visual design with responsive web development principles. It was built using HTML and CSS with a mobile-first approach, incorporating Flexbox for navigation and CSS Grid for overall layout. The goal of this project is to present my skills, experience, and creative work in a clear, accessible, and visually engaging format.

Pages Included
About (Home) – Introduction, visual identity, and overview of my design perspective
Work – Selected professional projects with context and problem-solving approach
Play – Creative experiments, exercises, and personal design work
Resume – Education, experience, and technical skills
